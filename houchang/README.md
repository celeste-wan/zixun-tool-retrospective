# 候场 · 面试练习网站公开演示

一个用 Vibe Coding 构建的面试准备工具。项目从个人实习求职需求出发，将面经整理、题目练习、经历表达与面试复盘连接起来。

此仓库是可公开分享的静态演示，复用原项目的界面与主要交互，所有预置材料均为专门编写的虚构示例。适合在简历或投递表单中展示项目。

## 体验流程

1. 在题库按岗位或题型筛选，先回答，再展开参考思路。
2. 保存自评和改进点，在复习页查看安排及历史回答。
3. 在收件箱查看示例面经与关联题目，或添加一条示例资料并整理为题目。
4. 在经历页查看示例项目的背景、行动、结果与口述表达。
5. 顶部“项目说明”介绍需求、构建方式与一次实际迭代。

## 静态版与原项目

| 范围 | 此仓库 |
| --- | --- |
| 题库检索、编辑、作答、复习、经历卡、案例 | 浏览器内可体验 |
| 数据保存 | 当前浏览器的 LocalStorage；不向服务器发送 |
| 简历上传 | 仅添加示例文件卡，不读取文件内容或保存原始文件名 |
| 简历下载 | 生成不含个人资料的示例文本文件 |
| 小红书面经采集、站外练习推送 | 原项目的外部流程；本静态版不执行 |
| 模型自动点评 | 本演示未接入 |

真实姓名、联系方式、学校、实习单位、简历文件、原始面经作者及个人练习记录均未包含在此仓库。项目使用者可自行输入演示文本，请勿输入敏感信息。点击顶部“重置演示”可清除本浏览器的试用记录。

## 构建与发布

需要 Node.js 22.13 或更高版本。

```sh
cd source
npm install
npm run dev
npm run build
npm run check
```

公开地址：https://celeste-wan.github.io/zixun-tool-retrospective/houchang/

仓库中的 `houchang/` 为演示静态产物，`houchang/source/` 为独立前端源码。构建后，`source/docs/` 中的产物可直接托管，资源采用相对路径。更新时将产物同步到 `houchang/`，保留 `source/` 源码目录。无需后端、账号或 API 密钥。

## 构建过程

项目负责人负责需求拆解、功能取舍、材料组织和使用验收，Codex 辅助完成界面、存储与部署。原项目中曾出现题目已保存、却因默认被归入“待完善”而难以找到的问题，后续调整了完成度判断、保存后的展示和弹窗内反馈。

项目目前主要用于个人求职准备，未声称具备大规模用户或量化提效结果。
