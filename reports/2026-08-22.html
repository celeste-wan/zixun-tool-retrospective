阿里云 未披露 客户案例/数据智能体
  • 客户场景：舟谱数据面向快消流通业务，把业务问题、指标解析、SQL 生成、安全执行和 API 草稿交付拆成可验证的 Agent 链路。
  • 技术底座：数据链路使用 Kafka、Flink、Hologres、MaxCompute 等产品；规划层通过 LangGraph、Subagent、版本化 Skill 和有界 Context 组织任务。
  • 可信机制：Skill 快照覆盖 296 个正式指标、33 个数据模块和 17 个维度定义，并以原指标项目生成的基准 SQL 验证 Text2SQL 语义。
  • 权限与交付：通过 AST 检查、MCP 网关、租户 ID 传播和只读数据库身份限制执行边界；验证后的 SQL 仅生成未发布 API 草稿，最终发布保留人工审核。
 从数据平台到智能数据助手：Agentic 数据分析与 API 生产实践
阿里云 未披露 大模型数据工程
  • 产品方案：EMR Serverless Daft 将 Common Crawl WARC/HTML 抽取、文本清洗、质量过滤、精确与近似去重、大模型标注、向量化和 OSS 交付组织进同一 DataFrame 管线。
  • 核心能力：提供正文抽取、HTML 清理、重复度与困惑度评估、MinHash、ai_query 和 ai_embedding 等算子，并支持并发、批处理、限流退让与 Token 统计。
  • 工程价值：统一承载 CPU 密集型清洗和网络密集型模型调用，减少单机脚本扩展、模型重复初始化、异常数据容错和多套 UDF 治理问题。
  • 适用范围：面向大模型预训练、微调和 RAG 建库前的数据准备；文章同时强调阈值需按语种和任务重新评估，清洗不等于完成隐私与版权合规。
 从 Common Crawl 到可训练语料：用 EMR Serverless Daft 构建清洗、模型标注与向量化管线
