  • 【华为-算子开发】CATLASS v2.0 正式发布 Python DSL，优化 MLA 调度并修复多类 Matmul 精度问题，降低高性能 AI 算子开发门槛。
  • 【华为-存储认证】NVFile 并行文件系统通过鲲鹏原生开发技术认证，在全闪存储、RDMA、AI 训练和推理加速场景披露多项性能数据。
  • 【阿里云-智能视觉】神眸与阿里云以端侧 AI 芯片、OSS 和 Tablestore 构建百万规模智能摄像头平台，覆盖视频存储、事件告警和自然语言检索。
  • 【华为-金融数据库】华为数据存储联合数据库厂商推进存算分离架构进入金融核心系统，案例显示网联业务交易处理能力提升 25%、查询时延降低 55%。
  • 【字节-智能体开发】火山引擎 Agent Plan 将全模态模型、豆包搜索、专业数据集、记忆、进化和 AI Native 开发底座整合进 DeepSeek Harness。
  • 【字节-数据分析】字节内部数据智能助手 iDA 从 ChatBI 演进为专业数据分析助手，将模型负责的任务理解与工程侧 SQL 改写、权限、枚举召回和执行解耦。
  • 【字节&蔚来-智能研发】蔚来在智能座舱研发中部署火山引擎 TRAE，开发人员日活跃率超过 70%，AI 代码采纳率 90%，并将代码审查、知识沉淀和问题定位纳入流程。
  • 【阿里云-模型服务】千问 AI 平台新增 GLM-5.3、DeepSeek-V4-Pro 正式版及 API，模型矩阵覆盖文本、代码、语音、图像和视频生成。
  • 【腾讯云-个人 Agent】开源 Octop 部署在腾讯云轻量服务器后，可接入微信和 QQ，承接水电结算、育儿提醒及个人工作台等长期任务。
  • 【阿里云-数据库】PolarDB Resource Control 和多租户能力分别解决海量 Agent 的计算资源争抢，以及并行任务间 Schema、测试数据和对象的隔离问题。
  • 【阿里云-AI Search】阿里云 AI Search 在 VDBBench、ES Rally Big5、Tantivy 和 MMEB VisDoc 等评测中披露向量检索、全文检索和多模态文档 Embedding 的阶段性成绩。
  • 【阿里云-批量推理】阿里云 EMR Serverless Ray 结合 Ray Serve LLM 和 Ray Data ai_query 部署 Qwen3.5 并执行高吞吐批量推理，支持自动流控、失败重试和弹性扩缩。
